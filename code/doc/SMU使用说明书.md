# SMU 使用说明书

> 基于 STM32F4 + ADS1115 的源表（Source Measure Unit）原型控制软件。
> 网页控制台与串口/HTTP 命令层共用同一命令引擎，行为完全一致。

---

## 1. 概述

| 项目 | 状态 |
|------|------|
| 电压输出（CV，0–15V） | ✅ 已完成 |
| 电压/电流实时测量（ADC） | ✅ 电压已完成；⚠️ 电流受硬件限制（见第 8 节） |
| OVP / OCP 保护 | ✅ 已完成（OCP 仅在电流可测 ~120mA 内有效） |
| 网页控制台 | ✅ 已完成 |
| 串口 / HTTP 命令层 | ✅ 已完成 |
| 校准（NV 保存） | ✅ 已完成 |
| 波形自适应显示 | ✅ 已完成（Y 轴自动缩放 + 刻度） |
| 电流输出（CC 源）/ 电流精密测量 | ⚠️ **未完成**（受电流检测硬件问题限制） |

## 2. 连接与网络

- **电源 / 输出端子**：按硬件定义连接 V+、V−（或对应香蕉头）。
- **USB（CH340N）**：虚拟串口，对应 `USART1`，参数 **115200-8N-1**，用于发送命令文本。
- **网络（RJ45）**：默认静态 IP **`192.168.7.200`**，子网 `255.255.255.0`，网关 `192.168.7.1`（存于 NV，可改为 DHCP 或静态）。
  - PC 需设同网段（如 `192.168.7.x`）。
  - 网页地址：`http://192.168.7.200/`，HTTP 端口 **80**。

---

## 3. 网页控制台（重点）

浏览器打开 `http://192.168.7.200/`，每 300ms 自动刷新一次实时数据。

### 3.1 实时数据卡（电压 / 电流）
- 大数字显示当前**测量值**（`vmeas` / `imeas`）与单位（V / mA），右侧"设定"显示 `vset` / `iset`。
- 下方**波形图**：滚动显示最近若干采样点。
  - **左侧 Y 轴竖线 + 刻度线与数值**：量程随波形幅度**自动调整**，吸附为 `1/2/5×10ⁿ` 的整数刻度，最高位标注单位（V / mA）。波形放大/缩小时，刻度数字与网格会一起重排。
  - 波形颜色：电压=蓝，电流=橙。

### 3.2 工作模式
五个按钮：**CV / CC / VM / IM / HIZ**，当前模式高亮。
- `CV`：恒压输出
- `CC`：恒流输出（⚠️ 受硬件限制未完全验证，见第 8 节）
- `VM`：电压测量（高阻，输出断开）
- `IM`：电流测量（高阻）
- `HIZ`：高阻 / 空闲

### 3.3 输出开关
`OUTPUT ON / OFF` 按钮：开启/关闭输出。开启时进入上一次选择的输出模式（CV 或 CC）。

### 3.4 设置与保护
- 电压设置：0–15V（`vset`）
- 电流设置：0–120mA（`iset`，CC 模式用）
- 过压保护 `OVP`（`vprot`）：1–15V，**默认 15V**（覆盖满程）
- 过流保护 `OCP`（`iprot`）：0.1–120mA，**默认 120mA**
- 滑块 / 输入框上限由固件实时下发的 `vmax` / `imax` 决定，与固件一致。

### 3.5 状态指示
- 状态药丸：`Ready`（自检通过）、`Prot`（保护锁存）、`Adc`（ADS1115 在线）、`Out`（输出已建立）。
- 错误框：出现 `err` 时显示错误码与中文描述。

### 3.6 校准卡片（CAL）
- `CAL:VOLT:ZERO` / `CAL:VOLT:GAIN` / `CAL:CURR:ZERO` / `CAL:CURR:GAIN` 对应按钮。
- `CAL:SAVE`：保存到 Flash；`CAL:DEF`：恢复默认标定（理论系数）。

### 3.7 离线 / 演示模式
- 后端不可达时页面进入演示模式（本地仿真动画）并周期性重连。
- **短暂断连（如 `CAL:SAVE` 保存时 ~1s 卡顿）不会误判为离线**，保持在线显示。

## 4. 命令层（网页与串口共用，重点）

所有设置最终都经过同一命令引擎（`SMU_CmdExecute`），保证网页与串口行为一致。
- 命令**大小写不敏感**，参数以空格或逗号分隔。
- 串口：USART1，每行以 LF/CR 结尾，回车即执行并返回响应。
- 网络：`POST /cmd` 请求体为一条命令文本。

### 4.1 通用 / 系统命令
| 命令 | 说明 | 返回示例 |
|------|------|----------|
| `*IDN?` | 查询身份 | `SMU, FW 0.1.0, SN:0001` |
| `*RST` | 复位：`vset=0, iset=0, vprot=15, iprot=120`，模式 HIZ，清除保护 | `OK` |
| `*CLS` | 清除保护锁存 | `OK` |
| `SYST:VERS?` | 固件版本 | `0.1.0` |
| `SYST:ERR?` | 读取并清除最后一个错误 | `0,"No error"` 或 `-110,"Parameter out of range"` |

### 4.2 模式与输出
| 命令 | 说明 | 返回 |
|------|------|------|
| `MODE CV\|CC\|VM\|IM\|HIZ` | 切换工作模式 | `OK` / 错误 |
| `MODE?` | 查询当前模式 | `CV` 等 |
| `OUTP ON\|OFF`（或 `OUTP 1\|0`） | 开启/关闭输出 | `OK` |
| `OUTP?` | 查询输出状态 | `1` / `0` |

### 4.3 设定值
| 命令 | 范围 | 说明 |
|------|------|------|
| `VOLT <v>` | 0–15 V | 设置电压设定值 |
| `VOLT?` | — | 查询 `vset` |
| `CURR <ma>` | 0–120 mA | 设置电流设定值（CC 用） |
| `CURR?` | — | 查询 `iset` |
| `VOLT:PROT <v>` | 1–15 V | 设置过压保护阈值（OVP） |
| `VOLT:PROT?` | — | 查询 `vprot` |
| `CURR:PROT <ma>` | 0.1–120 mA | 设置过流保护阈值（OCP） |
| `CURR:PROT?` | — | 查询 `iprot` |

### 4.4 测量与诊断
| 命令 | 说明 |
|------|------|
| `MEAS:VOLT?` | 测量电压（`vmeas`） |
| `MEAS:CURR?` | 测量电流（`imeas`，单位 mA） |
| `MEAS:ALL?` | 返回 `V=..,I=..` |
| `STAT?` | 状态字（16 位，见 4.7） |
| `RAW?` / `ADC?` / `ADCT?` | 诊断：原始 ADC 码值 / 通道状态 |
| `HW?` | 诊断：回显 PWM/IO 硬件实际状态 |
| `SYST:SELF` | 重新运行上电自检，返回 `SELFTEST: OK/FAIL` |

### 4.5 校准命令
| 命令 | 说明 |
|------|------|
| `CAL:VOLT:ZERO` | 电压零点校准（输入 ≈0V 时执行） |
| `CAL:VOLT:GAIN <v>` | 电压增益校准（施加已知电压 `v` 后执行） |
| `CAL:CURR:ZERO` | 电流零点校准 |
| `CAL:CURR:GAIN <ma>` | 电流增益校准（施加已知电流后执行） |
| `CAL:SAVE` | 保存标定到 Flash（约 1s，期间板子短暂冻结，返回 `OK`） |
| `CAL:DEF` | 恢复默认标定（理论系数） |

### 4.6 错误码
| 码 | 含义 |
|----|------|
| 0 | 无错误 |
| 100 | 命令错误 |
| 110 | 参数越界 |
| 120 | 模式切换被拒绝 / 忙 |
| 121 | 过压保护锁存（OVP） |
| 122 | 过流保护锁存（OCP） |
| 130 | ADC 通信失败 |
| 140 | 自检失败 |
| 150 | 看门狗复位 |

### 4.7 状态字 `stat`（位域）
| 位 | 含义 |
|----|------|
| bit0 `READY` | 自检通过 |
| bit1 `PROT` | 保护已锁存（需 `*CLS` 清除） |
| bit2 `ADC_OK` | ADS1115 在线 |
| bit3 `OUT_ACTIVE` | 输出已建立 |
| bit4 `PROT_ARMED` | 保护已武装（软启动完成后才允许 OVP/OCP 锁存） |

## 5. HTTP 接口（程序化控制）

除网页外，可直接调用 HTTP 接口做自动化：

- **`GET /data.json`** — 返回实时状态 JSON，字段：
  ```json
  {"mode":"CV","vset":5.000,"iset":0.000,"vmeas":5.0029,"imeas":0.3417,
   "vprot":15.0,"iprot":120.0,"vmax":15.0,"imax":120.0,
   "outp":1,"stat":29,"err":0,"j18":0,"fw":"0.1.0","ip":"192.168.7.200","mac":"00:80:E1:12:34:56"}
  ```
- **`GET /set?...`** — 批量设置，参数：`vset, iset, vprot, iprot, mode, outp`（如 `/set?vset=5&outp=1`）。每个参数经同一命令层校验。
- **`POST /cmd`** — 请求体为**一条**命令文本（即第 4 节的任意命令），如 `MODE CV`。返回该命令响应。
- 网页本身：`GET /`。

示例（curl）：
```bash
curl "http://192.168.7.200/set?vset=5&outp=1"
curl -X POST -d "MODE CV" "http://192.168.7.200/cmd"
curl "http://192.168.7.200/data.json"
```

## 6. 典型使用流程（CV 电压输出）

1. 上电，自检通过（串口打印 `READY. Send *IDN? to verify.`，网页 `Ready` 亮）。
2. 网页选 **CV**，设电压（如 5V），点 **OUTPUT ON** → 输出 5V。
3. 保护：`OVP` 默认 15V 已覆盖满程；如需更严格可下调。
4. 读数：`vmeas` / `imeas` 实时显示，波形图自动缩放。
5. 关闭：`OUTPUT OFF` 或 `MODE HIZ`。

---

## 7. 校准流程

1. **电压**：输出短路 / 0V 时点 `CAL:VOLT:ZERO`；施加标准电压（如 10.000V），点 `CAL:VOLT:GAIN 10`；点 `CAL:SAVE`。
2. **电流**：类似用 `CAL:CURR:ZERO` / `CAL:CURR:GAIN <ma>`。
3. 保存后断电不丢（存于 Flash NV）。`CAL:DEF` 恢复出厂理论系数。

> 注意：`CAL:SAVE` 会同步擦除一个 Flash 扇区，板子冻结约 1 秒后返回 `OK`，属正常；保存期间网页短暂不刷新不会误判离线。

## 8. 已知限制 / 待完成

- **电流检测硬件问题**：电流检测采用 INA128 + 采样电阻，存在共模电压问题。固件目前用临时拟合常数（等效 `RSENSE≈0.570`、`INA_GAIN≈30`），**可测上限约 120mA**。受此限制：
  - 电流测量（`imeas`）在 ~0–120mA 内可用，但精度 / 满量程需硬件修复后重新标定。
  - **CC（恒流输出 / 源）模式尚未完全验证**，不建议用于精密恒流。
  - OCP（过流保护）仅在 ~120mA 以内有效；**200mA 保护目标需更换电流检测硬件（降低 RSENSE / INA 增益）并重新标定**后才能实现。
- 电压输出（CV）功能完整：0–15V，OVP / OCP 可锁存，需 `*CLS` 清除。
- `CAL:SAVE` 约 1 秒卡顿（前端已容忍；彻底解法：NV 改为追加写，待做）。
- 看门狗当前默认关闭（诊断期），重开前需消除长阻塞。

## 9. 常见问题

- **网页显示"未连接到仪器"**：多为 `CAL:SAVE` 保存时的 ~1s 卡顿误判，现已容忍；若持续断连，检查网线 / 同网段 / IP。
- **第一条串口命令返回 `-100`**：上电初期首个字节偶发丢失，重发一次即可（固件已做接收兜底）。
- **输出 0.56V 而非 0V**：`VM` / `IM` 测量模式为高阻，浮空漏电 0.56V 属正常；要输出 0V 须进入 `CV` / `CC` 且 `OUTPUT ON`（此时低边管把输出钳在 0V）。
- **改 `vset` 后输出不更新**：确认处于 `CV` 且 `OUTPUT ON`；`VM` / `HIZ` 下输出级不驱动。
